# Monthly Sheet

The monthly sheet is the core workspace for the user.

## Main sections

- **Assigned Projects vs Logged**
- **Sheet**
- daily entry drawer or card for selected days

## Supported actions

- save draft progress
- submit the monthly sheet
- download CSV for the project summary section
- download CSV for the sheet section

## What the page depends on

The month page becomes meaningful after admin setup is complete:

- the user must exist
- a reviewer must be assigned
- projects should exist
- allocations should connect the user to at least one project
- shared fixed categories should be active

Without project allocations, the user can still see the page, but project-based entry will not represent the full intended workflow.

## Submission flow

1. Fill the required hours for the month.
2. Review logged totals and any notes.
3. Submit the month.
4. Wait for reviewer approval or reopen feedback.
