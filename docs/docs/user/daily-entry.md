# Daily Entry

The daily entry card is used to update a specific day inside the monthly sheet.

## Current behavior

- entries save as draft when you use the day-level save action
- the page provides loading and error feedback for sheet load and save states
- the draft save action confirms success with a toast message
- submitted and approved sheets are read-only

## Locked states

If a sheet is already submitted or approved, the form shows a lock message instead of suggesting that hours can still be edited.
