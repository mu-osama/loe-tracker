# Dashboard

The dashboard is your month summary view.

## What you can see

- total logged hours for the current month
- remaining hours
- days left in the month
- assigned project count
- fixed category count
- month guidance and reviewer context

## Why it matters

Use the dashboard to quickly decide whether:

- you still need to fill missing days
- the month is ready for submission
- the current sheet is already locked or approved

The dashboard is usually the fastest entry point before moving into `/loe` for detailed daily work.
