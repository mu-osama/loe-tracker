# User Management

## What admins can do

- create users
- edit user details
- activate or deactivate accounts
- assign reviewers
- export filtered user data as CSV

## Why this page matters

This page controls who can log in and who is responsible for reviewing a user's LOE submissions. The reviewer assignment is critical because the review queue uses that relationship.

## Required user fields

- name
- email
- password on create
- position
- department

Current fixed department values:

- `Engineering`
- `Experience`

## Recommended admin sequence

When onboarding a new person:

1. create the user
2. choose the correct role
3. assign the reviewer
4. set location and department details
5. save the user
6. move to allocation management and connect the user to projects

## Status handling

Activate and deactivate actions use in-app confirmation modals rather than browser alerts.
