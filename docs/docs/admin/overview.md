# Admin Overview

The admin overview page summarizes LOE status across the organization.

## Demo login credentials

- **Admin:** `admin@company.com` / `Admin@1234`
- **User:** `user@company.com` / `User@1234`

Use the admin account for the full management flow. Use the user account to test what a normal employee sees before returning to admin pages.

## What it is used for

- identify users who have not submitted yet
- monitor delayed sheets
- scan utilization levels
- export overview data as CSV

## Typical filters

- country
- city
- status
- over-utilized only
- target month and year
